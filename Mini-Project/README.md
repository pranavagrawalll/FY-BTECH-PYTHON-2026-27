# Digital Evidence Integrity & Verification System (DEIVS)

## Project Overview
DEIVS is a Python-based application designed
to maintain the integrity of digital evidence.

## Features
- Digital Evidence File Selection
- SHA-256 Hash Generation
- Evidence Integrity Verification
- Modification Detection
- Evidence Record Management
- Investigation Report Generation

## Technologies Used
- Python
- SQLite
- Tkinter
- Hashlib
